Endpoint
in package
  • Application
implements EndpointInterface uses EndpointTrait

Endpoint.php : 37

The route table for the MTGJSON v5 API — one constant per file the API serves under `https://mtgjson.com/api/v5/`, with `:param` placeholders bound via {@see EndpointTrait}. Same mechanics as DiscordPHP's own `Endpoint`, pointed at `mtgjson.com`.

MTGJSON is a file API: every route is a static JSON document wrapped as {"meta": {...}, "data": ...}, rebuilt daily. The bulk files (marked below) run from tens to hundreds of megabytes; card and set queries are answered from the SQLite build instead (see Database).
