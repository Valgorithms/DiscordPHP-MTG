SearchCache
in package
  • Application

FinalYes
SearchCache.php : 28

Short-lived state behind a message's components — a search's filters, an opened booster's cards — under an id short enough for a `custom_id`.

A component's custom_id holds at most 100 characters, too few for a set of search filters, so a results page carries card:page:<id>:<page> and the filters wait here. Entries expire after TTL and the oldest go first past LIMIT; a click on an expired one is told to search again. Kept in memory: a restart forgets them, as it would a conversation.
