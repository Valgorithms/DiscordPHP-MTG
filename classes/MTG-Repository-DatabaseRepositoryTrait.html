DatabaseRepositoryTrait

DatabaseRepositoryTrait.php : 35

`fetch()`, `fresh()` and `freshen()` for repositories answered from the local MTGJSON build instead of an HTTP endpoint. MTGJSON serves cards and sets only inside whole files, so there is no per-item route to call.
