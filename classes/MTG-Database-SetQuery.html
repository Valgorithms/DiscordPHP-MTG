SetQuery extends Query
in package
  • Application

SetQuery.php : 29

A set search against the AllPrintings build's `sets` table.

Every sets column is a filter: name, block and mcmName match partially, languages by membership, numbers with comparisons, is* columns as booleans, and the rest (code, type, parentCode, releaseDate, …) exactly. orderBy, page and pageSize (1-100, default 100) work as for cards. Unordered results are newest first.
